# システム・UI仕様 (System & UI Specs)

## 1. ランキングシステム
- **記録対象:** 各ステージごとのスコア
- **保存数:** 上位5件
- **ネームエントリー:** ハイスコア更新時、プレイヤーネームと共に保存・表示する

## 2. UI (User Interface)
- **技術スタック:** Unity uGUI (Canvas), TextMeshPro
- **HUD表示:**
  - **HPゲージ:** 現在のHPを表示（ハートアイコンやバーなど）
  - **SPゲージ:** 現在のSPを表示
  - **スコア:** 現在の獲得スコア
  - **発射点インジケーター:** 現在どの頂点が発射口になっているかを可視化

## 3. 技術・データ管理
- **静的データ:**
  - 敵パラメータ、ステージ設定等は `ScriptableObject` を活用して管理
  - インスペクターでの調整を容易にする
- **コーディング規約:**
  - フィールド: `[SerializeField] private` を使用
  - 非同期処理: `async/await` (UniTask推奨)
  - クラス/メソッド: PascalCase, 変数: camelCase
