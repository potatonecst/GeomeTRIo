# 自機仕様 (Player Mechanics)

## 1. 基本ステータス
- **形状:** 正三角形
- **HP (Hit Points):**
  - 設定可能範囲: 1 〜 10
  - デフォルト値: 3 (Settingsで変更可能)
  - **動的最大値:** 回復により現在HPが最大値を超えた場合、最大値も更新される
  - **回復手段:** スコアエクステンド（50,000点ごとに+1）
  - 0になるとゲームオーバー
  - **被ダメージ処理:** ダメージを受けると1.5秒間の無敵時間が発生（点滅演出あり）
- **SP (Special Points / Bombs):**
  - 設定可能範囲: 0 〜 10
  - デフォルト値: 2 (Settingsで変更可能)
  - **チャージシステム:** 敵撃破(+50)などでゲージを溜め、1000ポイントでストックが+1される
  - **上限:** ストック数の上限なし
  - 特殊アクション（スピンアタック）で使用

## 2. 攻撃システム
- **発射点:** 正三角形の3つの頂点（前方、左斜め後方、右斜め後方）
- **切り替え:** プレイヤー操作により、アクティブな発射口を左右に切り替え可能
- **弾道:** 選択された頂点の向きに合わせて発射
- **弾の形状:** **白の二等辺三角形** (White Isosceles Triangle)。進行方向を頂点とする。
  - **推奨サイズ:** 幅0.1, 長さ0.2 (Unity Unit)。鋭利な形状でスピード感を表現する。
- **連射機能:**
  - **手動連射 (Manual):** ボタンを押した瞬間に**バースト射撃**（複数発の高速連射）を行う。レベルアップによりバースト数が増加する（最大4点バースト）。
  - **オート連射 (Auto):** Settingsで有効化可能。ボタン押しっぱなしで連射する。レベルアップにより連射間隔が短縮される（Rapid Fire）。
  - **仕様の意図:** 手動操作には「瞬間火力」、オート操作には「安定した弾幕」という異なるメリットを持たせる。

## 3. 特殊アクション：スピンアタック
- **発動条件:** SPを消費して発動
- **効果:**
  - **持続時間:** 2.0秒
  - **状態:** 完全無敵状態になる
  - **攻撃:** 自機が高速回転（720度/秒）しながら、全3頂点から弾を乱射する
  - 「ボム」に相当する緊急回避兼広範囲攻撃手段

## 4. パワーアップシステム (Power-Up System)
- **レベルシステム:**
  - 経験値（EXP）を取得することで武器レベルが上昇する（最大Lv.10）。
  - **Lv.2, 5, 8:** 連射性能強化（手動ならバースト数増加、オートなら連射速度アップ）。
  - **Lv.3, 6, 9:** 攻撃力強化（弾のダメージ増加）。
  - **Lv.4, 7, 10:** 攻撃範囲強化（3-WAY -> 5-WAY -> 7-WAY）。サイドの弾は中央より威力が低く、見た目も薄い。
- **経験値アイテム:**
  - **形状:** 黄色のひし形（回転する正方形）。
  - **取得:** プレイヤーが接触すると取得。
  - **マグネット機能:** プレイヤーが一定距離（2.0m）以内に近づくと、高速で吸着して回収を補助する。
- **HUD表示:**
  - 現在のレベルと、次のレベルまでの経験値ゲージを表示。
  - レベルアップ時には画面中央およびログにメッセージを表示する。
