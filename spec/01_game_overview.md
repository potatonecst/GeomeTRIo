# ゲーム概要 (Game Overview)

## 1. コンセプト
「GeomeTRIo」は、三角形の幾何学的な特性と戦略的な発射点切り替えを組み合わせた2Dシューティングゲームです。
全方位（上部および下部）から迫りくる敵に対し、自機の形状（正三角形）と3つの発射点を切り替えて対抗します。

## 2. 基本ルール
- **勝利条件:**
  - **現状:** スコアアタックモードのみ（HPが尽きるまでプレイ）。
  - **展望:** 将来的にステージクリア型のキャンペーンモードを追加予定。
- **敗北条件:** 自機のHPが0になる
- **スコアシステム:**
  - **通常敵撃破:** 100点 + レベルボーナス
  - **追尾敵撃破:** 300点 + レベルボーナス
  - **ジャマー敵撃破:** 300点 + レベルボーナス
  - **誘爆ボーナス:** 敵スコア + 250点（敵同士の衝突）
  - **エクステンド:** 200,000点ごと

## 3. ゲームフロー
1. **タイトル画面:** ゲーム開始、設定など
2. **メインメニュー:**
   - **Stage1:** 通常ステージ
   - **ScoreAttack:** スコアアタックモード
   - **Ranking:** ランキング確認
   - **Settings:** 設定変更
3. **ゲームプレイ:**
    - 自機操作、敵撃破
    - HPが尽きるとゲームオーバー
4. **リザルト画面:** スコア表示、ランキング更新（ネームエントリー）
