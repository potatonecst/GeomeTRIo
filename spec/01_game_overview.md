# ゲーム概要 (Game Overview)

## 1. コンセプト
「GeomeTRIo」は、三角形の幾何学的な特性と戦略的な発射点切り替えを組み合わせた2Dシューティングゲームです。
画面下部から迫りくる敵に対し、自機の形状（正三角形）を活かした攻撃で対抗します。

## 2. 基本ルール
- **勝利条件:** ステージクリア（詳細条件は要定義、ウェーブ制などを想定）
- **敗北条件:** 自機のHPが0になる
- **スコア:** 敵の撃破、および敵同士の衝突による「誘爆」ボーナスなどで加算

## 3. ゲームフロー
1. **タイトル画面:** ゲーム開始、設定など
2. **ステージ選択:** プレイするステージを選択
3. **ゲームプレイ:**
    - 自機操作、敵撃破
    - HPが尽きるとゲームオーバー
4. **リザルト画面:** スコア表示、ランキング更新（ネームエントリー）
