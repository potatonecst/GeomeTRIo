# 敵キャラクター仕様 (Enemy Mechanics)

## 1. 基本挙動
- **難易度上昇:** ゲーム経過時間90秒ごとに、敵のHPが+1ずつ増加する
- **出現制御:** `EnemySpawner` により管理。敵同士が重ならないよう安全距離をチェックして生成される。
- **画面外判定:** 画面内に完全に入るまで（カメラ範囲 + マージン0.24）はダメージを受けない（無敵状態）。これにより、出現直後の理不尽な撃破を防ぐ。

## 2. 誘爆ギミック (Chain Explosion)
- **概要:** 敵同士が衝突した際、特殊な相互作用が発生する
- **発動条件:** タグ "Enemy" 同士の接触 (`OnTriggerEnter2D`)
- **効果:**
  - 衝突した敵は即座に破壊される
  - 衝突地点から**8方向（45度刻み）**に弾が発射される
  - プレイヤーに**5点**のボーナススコアが入る
- **戦略性:**
  - プレイヤーはこのギミックを利用し、意図的に敵を衝突させることで広範囲の敵を一掃（誘爆）することができる

## 3. 敵の種類
*(※現在は以下の2種類のみだが、今後挙動やバリエーションを大幅に増やす予定)*

### 通常敵 (EnemyController)
 - **形状:** **正方形 (Square)**。色は **赤 (#FF3333)**。
- **出現:** 画面**上部** (Y=6) から出現し、真下へ直進する。
- **攻撃:** 出現から一定時間経過後、弾を発射。さらに時間が経過すると自機狙い弾に変化する。
  - **弾の形状:** **赤のひし形** (Red Rhombus)。正方形を45度回転させた形状。
  - **推奨サイズ:** 0.15 x 0.15 (Unity Unit)。プレイヤー弾よりも太く、視認性を重視する。
  - **ドロップ:** 撃破時、20%の確率でパワーアップアイテムをドロップする。

### 追尾敵 (ChaserEnemyController)
 - **形状:** **円 (Circle)**。色は **赤 (#FF3333)**。
- **出現:** 画面**下部** (Y=-6) から出現（ゲーム開始20秒後から出現開始）。
- **挙動:** プレイヤーの位置に向かって移動（追尾）する。
- **攻撃:** プレイヤーに向けた弾を発射する。
  - **弾の形状:** 通常敵と同様、**赤のひし形**。
  - **推奨サイズ:** 0.15 x 0.15。
  - **ドロップ:** 撃破時、30%の確率でパワーアップアイテムをドロップする。

## 4. 視覚演出 (Visual Effects)
- **被ダメージ演出:**
  - **ヒットフラッシュ:** ダメージを受けた際、スプライトを一瞬（0.05秒）白く発光させる。
  - **HPバー:** HPが2以上の敵には、頭上に簡易的なHPバー（Sprite）を表示する。ダメージを受けた際は**左端を固定したまま右側が減少**する。
- **死亡演出 (Glitch Death):**
  - 爆発ではなく、デジタルなノイズ（Glitch）が走って消滅する演出を採用。
  - **ExplosionEffect:** 赤・白・シアンの横長パーティクルが、敵の形状範囲内で激しく明滅し、0.25秒程度で素早く消失する。
